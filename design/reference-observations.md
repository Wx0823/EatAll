# 本轮参考依据

来源为用户在本聊天提供的 QQ20260929-170159.mp4，约24.23秒，480×420。本稿引用本聊天前序的视觉抽帧分析，不是本轮重新播放，也不是原作源码。

| 时间约段 | 可见事实 | 本项目可研究的设计关系 |
|---|---|---|
| 0–3秒 | 短身体离开左上平台后下落 | 地形支撑与重力 |
| 3–8秒 | 局部果实消失，身体增长 | 收集改变可达范围 |
| 8–13秒 | 跨底部缺口，到右侧再折返 | 身体长度与转弯空间 |
| 13–16秒 | 接近悬挂果实后回头 | 目标可见不代表可达 |
| 17–22秒 | 从缺口到平台底部，沿左外墙吃果上行，尾部仍搭在平台 | 头部路线和尾部支撑必须同时规划 |
| 22–24秒 | 未见进入圆形目标，身体整体掉出画面 | 接近目标仍可能失去支撑；没有显示失败结算 |

没有从视频确认：原作名称、引擎、每颗增长量、果实碰撞/支撑属性、自碰规则、撤销、是否必须全收集、具体胜负结算顺序。它们在EatAll中由团队明确提出新规则，不宣称还原了原作。

本项目提炼的是“吃到食物后获得行动能力，地形使能力有用，失误可理解且容易重试”。不照搬视频关卡、美术或未经展示的商业化系统。
