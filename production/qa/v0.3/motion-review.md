# v0.3 操作节奏与动作独立评审

日期：2026-09-30。当前状态：新版独立验证通过，原图形缺陷已复验修复。仅评估确定性输入调度/真实渲染动作，不声称真机手感或帧率。

## 旧版基线

运行Godot4.5.1 headless，实例化真实main场景，隔离存档user://qa/motion-review.json，关闭app自动_process，手动每10ms更新，共2s。使用40格平坦走廊隔离夹具，远处食物与出口不会在采样时触发终局。通过方向回调启动持续向右，记录state.moves实际增加时刻。

旧版接受移动起步时间（秒）：`0.00, 0.49, 0.81, 1.13, 1.45, 1.77`。首个连走间隔490ms，后续320ms。动画与额外repeat等待叠加可在确定性采样复现，并非仅主观描述。采样不是屏幕帧率、触摸驱动延迟或真人体验测量。

测试文件：game/tests/test_motion.gd。其--baseline模式仅输出当前版本时序；旧版数字来自修改前本轮实际命令输出，不会用新版代码冒充旧版。

## 新版确定性独立验证

命令：`.tools/godot_console.exe --headless --path game --script res://tests/test_motion.gd`。首轮53项检查/0失败；追加下落、格边速度与冻结检查后最终73项/0失败，见末节。

- 10ms步长接受动作：`0.00,0.16,0.32,0.48,0.64,0.80,0.96,1.12,1.28,1.44,1.60,1.76,1.92`。
- 1/60秒步长接受动作：`0.00,0.1667,0.3333,0.50,0.6667,0.8333,1.00,1.1667,1.3333,1.50,1.6667,1.8333,2.00`。差异来自离散采样；没有动画后再叠加旧等待。
- 首按立即接受一步，中间渲染头坐标位于源/目标之间；短点按只一步，边界转向在180ms内接受正确方向，松手取消尚未执行转向。
- 墙体/直接掉头无状态/历史改变，改有效方向立即恢复；3秒单次delta不会追补成多格爆发，松手无积压动作。
- 暂停保持已提交逻辑/结束当前画面，恢复不继承held；移动中撤销与重开清理动画/重复；焦点丢失暂停且不额外走。
- 失败/胜利有终局表演窗口，期间不接受移动；撤销、重开取消旧延迟面板；撤销清理粒子/reaction；正常等待后胜利面板出现且步数不增加。

此测试通过真实main实例和状态验证输入调度，但直接调用方向回调和_process，不等同原生触摸或主观手感。原生事件链另由以下录制脚本验证。

## 真实图形动作与原生事件链

`game/tests/capture_motion.gd` 使用 Input.parse_input_event / Input.flush_buffered_events 发送ScreenTouch，轮盘和撤销按钮由原生事件经过实际UI处理。没有直接调用try_move/undo完成演示。使用正式关卡1、7、6和隔离QA存档；仅关卡切换由脚本调用。

实际执行命令：`.tools/godot_console.exe --path game --fixed-fps 60 --script res://tests/capture_motion.gd`。场景包含第1关长按连走并赢、第7关RR碰刺失败/实际点撤销/转向吃糖/连走再赢、第6关RRURD连续下落至出口；全部情节状态断言通过。已实际打开6张截图：吃糖运动帧、胜利、失败惊讶、转向吃糖、下落惊讶、落地胜利。可见头部变形/惊讶脸、星粒和落地姿态，并非只检查方法存在。

首次图形运行虽然退出0，但发现转向吃糖期间 `_tube` 多边形三角化失败约10次，属于画面阻断，已提交renderer作者修复；不能据退出码或状态断言宣称该次图形通过。下一节记录修复复跑结论。固定帧率录制只验证表现，不是设备FPS测量。

## 最终复跑与交付判断

renderer修复后，本评审者独立复跑原生触摸图形脚本，退出0、情节failures=0，完整输出未见ERROR/WARNING；重新实看01吃糖、04转角、05下落、06落地，无缺面/身体裂洞。修复针对每层带状几何三角化，自交大多边形不再交给引擎剖分；未通过压制日志绕过。capture的ensure已改为累计失败并决定最终退出码，避免中途quit(1)被尾部quit(0)覆盖；录影可传 `-- --audio` 开音效。

最终 `test_motion.gd` 实际结果：**73项检查，0失败，exit0**。补测内容：

- 连续下落每40ms头部y为 `3.000,3.128,3.512,4.152,5.048`，增量持续增加并跨过整数行；身体各节相对位移保持不变，落到正确终点。
- 落地粒子对应实际地形上方支撑格，而非漂在空中。
- 暂停后renderer关闭process，真实SceneTree多帧不改变反应计时；恢复process并经过实际树帧后反应推进。
- 固定10ms采样下，0.15s与0.17s的格边两侧位移对称，持续移动没有旧版逐格减速停顿。

测量限制：额外测试曾将0.15与0.01两个浮点delta相加，因边界精度与单一10ms采样略有差异，动作在下一采样帧结束；测试改为统一10ms步进再比较速度。不能将“0.16秒目标”描述为任意可变帧长下精确到毫秒，无需为1帧量化差异宣称新卡顿问题。脚本中间坐标检查现在也防止空渲染覆盖数组引起夹具异常。

**结论：通过本轮操作调度与代表情节动作回归。** 可见动态表情、压缩伸展和粒子已进入真实场景，原生触摸情节可完成；不等于用户已认可喜剧效果，不声称真实Android触屏手感、全设备FPS或所有长体转角全覆盖。固定步长影像是表现证据，主观体验仍需用户试玩反馈。
